## 一、产品概述

### 1.1 产品定位
PixelCraft 是一款轻量级纯前端像素风图片转化工具，面向普通用户，无需登录即可使用。用户上传图片或拍摄照片后，可通过调节像素块大小、色彩深度，选择不同调色板风格，一键生成像素风图片并下载。

### 1.2 产品价值
- **低门槛**：纯浏览器端运行，无需安装，打开即用
- **即时反馈**：实时预览像素化效果，支持与原图对比
- **风格丰富**：内置多种经典像素调色板，支持赛博朋克等潮流风格
- **零成本**：纯前端实现，无服务器成本，本地存储历史记录

### 1.3 核心流程
```
上传图片/拍摄照片 → 调节参数（像素块大小、色彩深度）→ 选择调色板风格 
→ 点击「像素化」→ 预览结果 → 对比原图 → 下载图片
```

## 四、核心功能详细说明

### 4.1 图片上传
- **支持格式**：JPG、PNG、WebP、BMP
- **尺寸限制**：建议最大 4096×4096 像素（超出则自动等比压缩至 4096 边）
- **文件大小限制**：建议 ≤ 20MB
- **交互**：拖拽上传区域 + 点击选择文件，支持移动端相册选择

### 4.2 摄像头实时拍摄
- 调用 `getUserMedia` API 访问摄像头
- 支持前后摄像头切换（移动端）
- 实时预览摄像头画面，点击「拍摄」截取当前帧并进入像素化处理流程
- 拍摄后的图片同样受尺寸限制约束

### 4.3 像素块大小调节
- **控件**：横向滑块 + 数字输入框
- **范围**：建议 2 ~ 64 像素/块（默认值可由算法根据图片尺寸自动推荐）
- **实时预览**：拖动滑块时实时更新预览（节流处理，避免卡顿）

### 4.4 色彩深度调节
- **控件**：横向滑块 + 数字输入框
- **范围**：2 ~ 256 色（对应调色板颜色数量）
- **说明**：色彩深度越低，颜色越统一，像素风效果越强烈

### 4.5 调色板风格
内置以下调色板选项（以卡片/色块形式展示，点击选中）：

| 风格名称 | 色调特征 | 典型用途 |
|---------|---------|---------|
| GameBoy风 | 4级绿色灰度 | 复古掌机风格 |
| 复古街机风 | 高饱和红/蓝/黄/绿 | 80-90年代街机感 |
| 经典像素游戏风 | 16色万能调色板 | 通用像素风 |
| 赛博朋克风 | 霓虹粉/蓝/紫 + 深色背景 | 科技感、潮流视觉效果 |
| 自定义调色板 | 用户自定义颜色列表 | 个性化需求 |

- **自定义调色板**：点击「自定义」后弹出颜色选择器，最多支持添加 16 种颜色

### 4.6 像素化转换
- 点击「像素化」按钮触发转换
- 转换过程显示加载动画（像素风Loading动画）
- 算法：将图片缩小至 `原尺寸/像素块大小` → 用最近邻插值放大回原尺寸 → 按选定调色板量化颜色
- 转换完成后自动展示结果预览区

### 4.7 原图对比滑块
- 在结果预览区上方/侧边提供「对比」切换按钮
- 开启后显示原图与结果图的左右/上下对比滑块（可拖动分割线）
- 移动端默认上下对比（适配竖屏）

### 4.8 重置功能
- 点击「重置」按钮，清除当前处理结果，保留原图，参数恢复默认值
- 二次确认弹窗（防止误操作）

### 4.9 下载图片
- **支持格式**：PNG（默认）、JPG（可选质量）、WebP
- **分辨率选项**：原始尺寸 / 2x / 4x（像素风放大，保持锯齿感）
- 点击下载按钮后出现格式与分辨率选择弹窗

### 4.10 历史记录（浏览器本地）
- 使用 `LocalStorage` 保存最近 20 条处理记录
- 每条记录包含：缩略图、处理参数、时间戳
- 点击历史记录可重新加载该次处理参数和结果
- 支持清空历史记录
- 数据仅保存在当前浏览器，清除浏览器数据后消失

## 五、非功能需求

### 5.1 性能要求
| 指标 | 要求 |
|-----|------|
| 图片上传响应 | < 2秒（含压缩） |
| 像素化处理时间 | 小于 4096×4096 图片 < 3秒 |
| 滑块实时预览延迟 | < 100ms（节流后） |
| 页面首次加载 | < 3秒（需优化静态资源） |

### 5.2 兼容性
| 平台 | 要求 |
|-----|------|
| 桌面端浏览器 | Chrome 90+ / Firefox 88+ / Safari 14+ / Edge 90+ |
| 移动端浏览器 | iOS Safari 14+ / Android Chrome 90+ |
| 响应式适配 | 支持 320px ~ 1920px 宽度 |

### 5.3 安全要求
- 纯前端处理，图片不上传至任何服务器，保护用户隐私
- 摄像头权限需用户主动授权，授权后方可使用拍摄功能

### 5.4 可访问性
- 支持键盘操作（Tab 切换焦点，Enter/Space 激活按钮）
- 滑块控件需有完善的 ARIA 标签

## 六、技术方案

### 6.1 技术栈选型

| 层级 | 技术选型 | 理由 |
|-----|---------|------|
| 核心语言 | HTML5 + CSS3 + JavaScript (ES6+) | 纯前端，无框架依赖，轻量 |
| 像素处理 | Canvas API（`getImageData` / `putImageData`） | 浏览器原生支持，性能优秀 |
| UI组件 | 原生实现 + 少量 CSS 动画 | 保持轻量，像素风UI自行绘制 |
| 响应式布局 | CSS Grid + Flexbox + 媒体查询 | 兼容桌面端和移动端 |
| 本地存储 | LocalStorage | 保存历史记录 |
| 摄像头 | `getUserMedia` API | 实时拍摄功能 |
| 构建工具 | 无需构建，直接打开 HTML 即可运行 | 极致轻量 |

> **说明**：经评估，本项目功能聚焦、逻辑清晰，使用原生 JavaScript + Canvas API 即可稳健实现，无需引入 React/Vue 等框架，避免额外的加载开销和复杂度。若后续功能扩展需求增加，可考虑引入轻量框架。

### 6.2 核心算法描述

**像素化算法**：
```
1. 将原图绘制到离屏Canvas，缩小至 (原宽/像素块大小) × (原高/像素块大小)
2. 使用最近邻插值（imageSmoothingEnabled = false）放大回原尺寸
3. 遍历每个像素，将其颜色映射至当前调色板的最近颜色（欧氏距离）
4. 将处理后的 ImageData 绘制到主Canvas输出
```

**调色板量化**：预定义各风格的RGB颜色数组，对每个像素的RGB值计算与调色板中每个颜色的距离，取最小值对应的颜色。
