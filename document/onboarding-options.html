Pixelate_Filter Onboarding 方向对比

6 个差异明显的动态复古像素艺术方案：布局、语气、信息密度各有侧重。

参考方向来自复古 / Pixel Art 落地页灵感集合，如 Dribbble Pixel Art UI、One Page Love Pixel Art、Lapa Ninja Retro Style 等；色调与功能锚定当前系统：米白背景、像素红、街机蓝、紫、绿、Canvas 像素化、调色板、导出与历史记录。

01. 爆开彩块 Hero

视觉冲击 / 低信息
CANVAS LIVE
RETRO PALETTE

把任意图片炸成复古像素画

上传或拍摄一张图片，Pixelate_Filter 会用 Canvas 实时压缩色彩、放大像素块，并套上 GameBoy、Arcade 或 Cyberpunk 调色板。

取舍：最有记忆点，适合年轻、创作型工具；但功能解释少，首次用户可能需要下滑或二级引导。

02. 街机投币开场

游戏感 / 情绪化
SCORE 0020PIXEL MODE

INSERT IMAGE TO START

PRESS START
TO PIXELATE

像打开一台街机：投进图片，选择块大小与色彩深度，再导出你的复古战利品。

取舍：沉浸感强，按钮行为非常明确；但整体偏暗、偏游戏化，可能弱化“专业图片工具”的可信度。

03. GameBoy 掌机说明书

怀旧 / 极简

一张照片，四阶绿屏灵魂。

选择 GameBoy 调色板，降低色彩深度，保留最硬朗的像素边缘。适合想快速得到经典掌机味道的用户。

取舍：风格统一、安静、复古味浓；但色彩不够饱满，和系统多调色板能力的关联较窄。

04. 工具台快速导览

产品清晰 / 高信息

先看懂，再开始像素化。

把 onboarding 做成缩小版工作台：左侧导入与参数，右侧实时预览，底部展示导出格式和历史记录。

控制面板

取舍：最利于解释系统功能，上手成本低；但惊喜感弱，更像产品导览而非个性化开场。

05. Cyberpunk 调色实验室

饱和霓虹 / 中信息

把照片送进霓虹调色实验室

从原图色彩到 Cyberpunk、Arcade、经典 16 色，每一次映射都像给图片换一台复古显示器。

GAMEBOY
ARCADE
CYBER

取舍：颜色最饱满，能突出调色板能力；但霓虹感较强，可能偏离当前米白轻复古主界面。

06. 像素漫画三步故事

亲和叙事 / 中高信息
嘿，把我变成像素风！

从照片到像素作品，只走三格漫画。

用更亲切的语气带用户完成：导入图片、选择风格、导出作品。

1 导入：上传 / 拖拽 / 摄像头
2 调整：块大小 / 色深 / 调色板
3 导出：PNG / JPG / WebP

取舍：亲和、解释完整，适合大众用户；但比方案 01/02 少一些强烈品牌气势。
